# Format Tracer

関数やメソッドの説明に添える呼び出し経路を整形する。元の質問への回答は通常どおり行い、その回答に以下の経路ブロックを添える。経路の出力だけを頼まれた場合は、ブロックだけを返す。

- `[呼び出し経路]` と書き、次の行から呼び出し元 → 呼び出し先の順に、1 ステップずつ改行して並べる。2 行目以降のステップには `→ ` を付ける。
- 各ステップは `シンボル名（ファイル名:行番号）` とする。ファイル位置には確認済みのコードへのリンクを付ける。
- 経路ブロックは見出しと経路だけで構成する。番号、役割の説明、補足文は入れない。
- 質問の対象を含む短い区間を選ぶ。分岐は別の経路ブロックにする。追加調査には `code-tracer` を使い、未確認の接続は載せない。

## 出力例

[呼び出し経路]\
main（main.go:11）\
→ deploy.Runner.Run（runner.go:68）\
→ config.Load（config.go:26）
