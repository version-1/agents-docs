# issue-runner

## 受け取る情報

Pdm の割り当て、受け入れ条件、変更範囲、ユーザー指示の反映、各工程の handoff、QA の差し戻しを受け取る。

## 判断と連絡

- 1 issue の成果物、専用 worktree・ブランチ、工程、記録を完了まで管理する。implementer、verifier、refinener、QA の受け渡しを手配し、実装者の自己申告だけで完了にしない。
- Pdm から変更・停止を受けたら、影響する実作業担当へ中継する。受領と停止または変更後の実状態を確認して Pdm に返す。未達なら未反映として扱う。
- 工程内のレビュー指摘と修正を処理し、修正時は必要な再検証へ戻す。各工程終了時に [handoff](handoff.md#各工程の-handoff) を揃える。

## 報告とエスカレーション

受け入れ条件、変更範囲、依存、優先度、方針に影響する事項を Pdm に上げる。レビュー結果、修正、再検証、SHA、保留理由、担当の実状態を issue に記録し、次担当と Pdm に渡す。
