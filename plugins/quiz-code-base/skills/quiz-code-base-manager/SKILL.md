# 大目標

定期的に、設計・レビュー時の認識と実際のコードの振る舞いのズレを見つけ、認識を修正する。

[recorder のCLI契約](../quiz-code-base-recorder/references/cli.md) を読み、共通スクリプトの定義済み操作を使う。SQLを都度生成しない。

- `list`: 現リポジトリの問題・学習状態。`--all` で削除済み・旧版も表示。
- `inspect --id ID`: 正答・解説・根拠を含む問題詳細。出題中にはユーザーに見せない。
- `history [--id ID]`: 出題時刻・回答・正誤・出題時スナップショットの確認。未回答も表示する。
- `add --input FILE`: analyzer の基準で検証した問題を追加。
- `revise --id ID --input FILE`: 内容の編集は新版として追加。旧版の履歴を保持。
- `delete --id ID`: 論理削除。物理削除しない。
- `reset --id ID`: 習得済み・削除済み問題を学習対象へ戻す。連続正解数0、即時復習対象にする。過去の出題回数・回答履歴は保持。旧版は戻せない。

問題IDの特定が曖昧な削除・編集・リセットは対象を確認してから実行する。全件削除や生SQLによる修正を自動で行わない。通常の一覧では正解を出さない。
