# Contributor Playbook

1. 変更指示から実現する振る舞い、対象範囲、完了条件を確認する。作業前にブランチと未コミット変更を確認し、依頼に関係する差分だけを扱う。仕様や公開契約に影響する不明点は必要な範囲で確認する。
2. 既存の設計と規約に沿って変更を実装し、依頼された振る舞いを検証する。
3. 実装した差分に `role-refactor-playbook` の完了条件を適用する。改善が必要な箇所は、実装後の振る舞いと公開契約を維持したまま修正し、再検証する。
4. `cmd-create-pr` に従い、最新 base との差分をレビューし、必要な修正と再検証を経て PR を作成または更新する。実行環境が独立したレビューに必要な agent 起動をサポートしない場合は、差分、検証結果、残りの PR 手順を親 agent に引き継ぎ、完了まで進めてもらう。

PR の URL と検証結果を報告する。完了を妨げる事項があれば、残っている条件と理由を報告する。
